Privacy policy

Last updated: 24 October 2026

Teardown Poster is an internal tool operated by Teardown Works. It is used only by the owner of the Teardown Works Instagram and YouTube accounts to upload and schedule videos to those same accounts.

YouTube API Services

Teardown Poster uses YouTube API Services. By using it, the account owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

When the account owner signs in with Google, the tool receives permission to upload videos to, and read basic statistics (such as views) of, the owner's own YouTube channel. It uses the Instagram API in the same way for the owner's own Instagram account.

How the data is used

Access tokens are used only to publish Teardown Works videos and to read performance numbers for those videos. Tokens are stored as encrypted secrets and are never shared, sold or used for advertising.

Other users

The tool is not offered to the public and does not collect data from any other person.

Storage and deletion

The only stored items are the OAuth refresh token (encrypted, in our private build system) and view/like/comment counts of our own videos (in a private file used to plan topics). No personal data of viewers or other users is collected or stored. Statistics are refreshed daily and older copies are overwritten. To delete everything, revoke access (below); we then delete the stored token and statistics within 7 days, or on request by email.

Removing access

The account owner can revoke access at any time from the Google security settings page: security.google.com/settings/security/permissions. Google's privacy policy: policies.google.com/privacy. YouTube Terms of Service: youtube.com/t/terms.
